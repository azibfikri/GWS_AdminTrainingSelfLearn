GWS Admin Study Desk — Mac

INSTALL
1. Unzip this file (you should see “GWS Admin Study Desk.app”).
2. Drag the app into Applications (or leave it in Downloads).
3. First launch: right-click the app → Open → Open
   (Gatekeeper blocks unsigned personal apps once; after that, normal double-click works.)

If macOS says the app is damaged / can’t be opened:
  System Settings → Privacy & Security → scroll down → Open Anyway
  Or in Terminal:
    xattr -cr "/Applications/GWS Admin Study Desk.app"

NOTES
- This build is for Apple Silicon (M1 / M2 / M3 / M4).
- If your Mac is Intel, ask Azib for the Intel build, or use the browser:
