GWS Admin Study Desk — Windows

Share this zip with your friend.

INSTALL (recommended)
1. Unzip the whole folder (do not run the .exe from inside the .zip).
2. Double-click Install.bat
3. Allow Windows Defender / SmartScreen if prompted:
   More info → Run anyway (unsigned personal study app)
4. Desktop + Start Menu shortcuts are created; the app opens.

QUICK RUN (no install)
- Double-click "GWS Admin Study Desk.exe" inside the unzipped folder.

UNINSTALL
- Run Uninstall.bat from this zip, or delete:
  %LOCALAPPDATA%\GWS Admin Study Desk
  and remove the Desktop / Start Menu shortcuts.

NOTES
- Windows 10/11 64-bit
- Practice progress saves in the app (localStorage)
- Not affiliated with Google or the official exam
- Browser alternative: https://gws-admin-study-guide.vercel.app/
